## [v26.2.2](https://github.com/redpanda-data/redpanda-operator/releases/tag/charts%2Fredpanda%2Fv26.2.2) - 2026-08-14
### Changed
* Bump operator sidecar image tag to v26.2.2 release
### Fixed
* The preStop lifecycle hook no longer stalls pod termination — or SIGTERMs a broker mid-drain — and bounds its admin API calls.

  Enabling maintenance mode on a broker whose node id is no longer a cluster
  member answers 404 forever; the hook now skips the drain on a 404 instead of
  retrying until its timeout (half the termination grace period). A 400 — the
  single maintenance slot is busy with another draining broker — still retries,
  preserving the drain serialization rolling restarts rely on. The
  drain-completion poll now waits until draining has actually begun before
  accepting draining=false, so a broker is never SIGTERMed while still holding
  all its partition leadership; the node-id lookup that precedes the drain is
  bounded so a crashlooping broker whose admin API never binds no longer spins
  the whole grace period; and every admin-API curl in the hooks carries a
  per-request timeout so one hung connection cannot freeze the hook.
