## [v26.2.4](https://github.com/redpanda-data/redpanda-operator/releases/tag/charts%2Fredpanda%2Fv26.2.4) - 2026-09-23
### Added
* New `commonAnnotations` value adds the given annotations to every object the chart renders, including the StatefulSet itself. The StatefulSet's Pod template and volume claim templates are deliberately left unannotated: the claim templates are immutable on a live cluster, and annotating the Pod template would restart every broker. Annotations set on an individual resource take precedence. Useful for policy-engine required annotations or ArgoCD sync waves, for example `argocd.argoproj.io/sync-wave: "1"`.
### Changed
* Bump operator sidecar image tag to v26.2.4 release
### Fixed
* `resources.memory.container` no longer publishes a description belonging to another value

  The Helm reference showed "Enables memory locking. For production, set to `true`."
  for `resources.memory.container`. That text was written for the commented-out
  `resources.memory.enable_memory_locking` above it. The memory sizing guidance that
  also appeared there is unchanged.
* `helm install` prints the post-install notes again
